# Math-Angat!: A Mobile E-Learning Game
 
> A 2D Android adventure game that teaches Grade 9–10 Mathematics through level-based problem solving — built with Unity and C#.
 
---
 
## About
 
**Math-Angat!** is an educational mobile game developed as an undergraduate thesis at Bulacan State University (BS Mathematics with Specialization in Computer Science), completed July 2024.
 
The game helps Grade 9 and 10 students strengthen their Math skills by wrapping problem sets inside an adventure game loop. Players progress through three worlds by correctly solving math problems — turning what's usually a stressful subject into an engaging challenge.
 
**Topics covered:**
- Quadratic equations
- Rational algebraic equations
- Quadratic inequalities
- Quadratic functions
---
 
## Gameplay
 
Players control a character navigating three distinct environments:
 
| World | Theme |
|-------|-------|
| 🗻 Cave | Entry-level challenges |
| ☁️ Cloud Village | Intermediate problems |
| ⚔️ Final Scene | Boss-level difficulty |
 
Each level presents math problems the player must answer correctly to advance. Wrong answers block progress — encouraging genuine learning, not guessing.

## What I Built
 
- **Level progression system** — three worlds with gated advancement based on correct answers
- **Question engine** — dynamic problem delivery tied to Grade 9–10 Math curriculum
- **2D character & environment art** — all sprites and scene assets designed in Photoshop
- **Android build pipeline** — optimized for low-spec devices down to Android 6 (Marshmallow) with 2GB RAM
- **Sound design** — background music and SFX integrated via Unity Asset Store
